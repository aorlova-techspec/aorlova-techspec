## ✨ Как я работаю с вайбкодингом

**Идея → ТЗ → AI-разработка → интеграции → тестирование → деплой → улучшения.**

1. **Разбираюсь в задаче.** Выясняю, кто будет пользоваться продуктом, какие есть ограничения и что должно работать.
2. **Проектирую решение.** Описываю экраны, пользовательские сценарии, данные и бизнес-логику.
3. **Разрабатываю с AI.** Использую OpenCode и другие AI-инструменты для итеративной реализации, проверки гипотез и ускорения разработки.
4. **Соединяю сервисы.** Настраиваю интеграции, API, автоматические действия и передачу данных.
5. **Тестирую.** Проверяю реальные сценарии, нахожу ошибки, улучшаю интерфейс и логику.
6. **Публикую и развиваю.** Разворачиваю проект, проверяю его в работе и добавляю новые возможности.

**AI помогает мне писать код быстрее, но ответственность за постановку задачи, качество и результат остаётся за мной.**
